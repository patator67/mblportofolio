### 3.2 Airbus Helicopters — Marseille, France
- **Role:** System & Command Engineering Intern
- **Period:** May – July 2023
- **Department:** Flight Controls — fly-by-wire architecture and systems
- **Programme:** VTOL CityAirbus NextGen (eVTOL urban air mobility prototype)

#### About Airbus Helicopters Flight Controls / CityAirbus
The CityAirbus NextGen is an all-electric, 4-seat eVTOL aircraft with fixed wings, V-tail, and 8 distributed electric propellers. The Flight Controls department develops the fly-by-wire (FBW) architecture replacing traditional mechanical control linkages with a single-stick digital interface managing all three axes. The software-defined control system handles automatic stabilisation, envelope protection, and facilitates hover-to-cruise transitions. The internship project involved modelling the dynamic behaviour of a toothed belt drive system connecting engines to propeller in the VTOL prototype powertrain.

#### Technical Project Detail
**Dynamic Model of a Toothed Belt:**
Objective: model the dual-engine/toothed-belt/propeller system and identify key characteristics — stiffness (k) and damping (c). Three phases:
- *Analytical model:* equations of motion derived; inertias converted to masses, belt modelled as spring; eigenvalue calculation giving natural frequency = **48.45 Hz**
- *Simulink model:* coupled rotor system built in Simulink with spring energy and damping; aerodynamic drag (scales with velocity²) added; model frequency = **49.12 Hz** (close to analytical)
- *Empirical model:* manufacturer FE model used to extract k and c as functions of RPM and torque; surface equation fits performed in MATLAB; implemented in Simulink for realistic variable-parameter simulation
- *Control:* electronic damping implemented via feedback on rotor-motor velocity difference; PID controller tuned using MATLAB PID Tuner app with low-pass filter for limited-bandwidth electric command system; saturation blocks on k and c to handle initialization instabilities; robust PID using `ureal` uncertain variables validated against multiple input scenarios
